# 排字工单 / Composing Stone — 添加单词 · 网络词典 · 管理标签

## A. 艺术主张

这三块不是「页面」，是同一张**排字工单**：没有卡片、没有圆角、没有阴影、没有弹窗，只有固定栏宽的网格、1px 发丝线，和一条永远空着的尾栏。三个结构上非常规的决定：

1. **输入框不存在**——单词是 88px 的衬线字块，光标进入时界面不换控件，只点亮左侧栏号、让下划线从左生长；「焦点」是版面事件，不是描边变色。
2. **词典是并置的第二版面**，不是面板也不是抽屉：它有自己的左轴与 colophon，与表单共享水平基线，物理上不可能盖住表单。
3. **≥1280 时尾栏恒空 96px**：这是呼吸口，也是「排版」与「卡片堆」的分界。

动效只有三种语法：线的生长、字块的位移、遮罩的揭示。**不使用透明度淡入。**

## B. 布局

统一骨架（三屏逐像素相同）：顶条 56/64 → 发丝线 → 正文网格 → 发丝线 → colophon 40。所有分隔线用绝对定位伪元素（`inset-inline:0; height:1px`）画，**不占布局宽度**（390 不会因 1px 溢出）。

- **≥1280**：`max-w-[1440px] mx-auto px-12`，`grid-template-columns: 96px minmax(0,1fr) 32px 432px 96px`（标记栏 / 表单 / 栏间 / 词典 / 空尾栏；1440 视口下表单实测 688）。标记栏放栏号 `01–04` 与字段短横；栏间 32 里发丝线画在正中；多余宽度全给外侧留白，栏宽不变。
- **1024–1279**：`72px minmax(0,1fr) 28px 336px`，`px-8`，尾栏归零。**词典仍并置、永不叠放。**
- **768–1023**：`minmax(0,1fr) 24px 272px`，`px-6`；标记栏塌回字段上方（栏号与标签同行）。
- **390**：单栏 + **上下分屏**。`grid-template-rows: 56px var(--split) 44px 1fr`；`--split: 54%`（844 高 → 表单 ≈402 / 把手 44 / 词典 ≈342），两块各自 `overflow-y:auto`。表单 `:has(input:focus, textarea:focus, select:focus)` 时 `--split: 74%`（≈551/193），词典退成「搜索框 + 已选 N 条 + 加入」一行，键盘不遮任何字段。把手 44px，左「02 词典」右「01 表单」，点击 / ↑↓ 切两档。
- **非对称**：左轴永远 x=0，右轴永远不齐——表单右缘是硬边，词典内容再缩进 32，读起来是「主栏 + 边注（marginalia）」而不是两个等权面板。
- **三屏落位**：单词页 = 标记栏（01 词头 / 02 释义 / 03 例句 / 04 标签）+ 表单 + 词典栏；词典栏内部四段（搜索 56 / 来源 44 / 结果流 1fr / 底栏 56）；标签页 = 标记栏 + 表单 + 右栏「待保存改动清单」（由现有 draft 状态派生，无需新接口）。
- **分隔语法**：栏与栏用**双线**（1px + 3px 间隔 + 1px），块内行用单线。单线 = 同行，双线 = 换块，读版不靠留白猜测。
- **状态件（三处，全部长在版面上，不用浮层）**：① 未保存 = 顶条中部 D6 一行 `未存 3 处`（tabular，clay 只染数字）；② 错误 = 保存条上方恒定 44 高的一行（2px clay 左标 + D5 文字），换文案不推挤版面；③ 词典回填 = 被填字段下沿一行 D6 `+ 已填入 3 条释义 / 撤销`，撤销是 44 高的纯文字按钮、下划线从左生长，`added === 0` 时只写「没有新增」且不渲染撤销。

## C. 排版（8 级；字号 = `≥1280 · 768–1279 · 390`）

| 级 | 用途 | 字体 | 字号 | 字重 | 字距 | 行高 |
|---|---|---|---|---|---|---|
| D0 | 词头单词 | serif | 88·64·48 | 400 | -0.035em | 0.92 |
| D1 | 界面标题 / 空态大字 | serif | 44·36·30 | 400 | -0.02em | 1.0 |
| D2 | 栏号 / 区块标签（释义·例句·标签） | sans 大写 | 11·11·11 | 700 | 0.24em | 1.2 |
| D3 | 音标 | serif | 20·18·16 | 400 | 0.02em | 1.2 |
| D4 | 释义正文 | sans | 17·16·16 | 400 | 0.005em | 1.55 |
| D5 | 词典义项 / 例句 | sans | 15·15·14 | 500 | 0.01em | 1.5 |
| D6 | 元数据（来源·词数·未存 N 处） | sans tabular | 11·11·10 | 600 | 0.14em | 1.2 |
| D7 | 动作文字 | sans | 13·13·13 | 600 | 0.06em | 1 |

- **靠字体本身当装饰的是两层**：D0 词头（单词就是海报，字号承担版面的全部视觉重量，不需要任何图形）；D2 栏号（0.24em 字距的 11px 大写，同时充当结构标记、锚点与快捷键提示——不是装饰）。
- DM Serif Display **只有 400、无 italic 文件**：衬线层级只能靠字号、字距、墨量（charcoal/70 与 /100）拉开，**永远不加粗、不用假斜体**。Plus Jakarta 是 300–800 变量字体，D2 / D6 / D7 的 600 / 700 靠它。
- 数字一律 `tabular-nums`；条数用 D1 级衬线数字（「03」）排在栏号位，让「3 条释义」成为版面元素而不是一句文字。

## D. 表面与材质

- 只有两种面：纸面 `ivory`、墨面 `charcoal`。层次靠 **alpha 阶梯**：`charcoal/4`（次级面，如词典栏底）· `/8`（悬停行）· `/12`（发丝线）· `/28`（选中行左标）· `/45`（元数据）· `/70`（次正文）· `100`（主正文 / 实心块）。
- 强调只有一处：`clay` 只给「当前焦点」「刚被加入的项」「错误」，面积永远 ≤ 一行字；`sage` 只做「草稿 / 新增」的 2px 左标；`sand` 只做悬停行底（`/18`）。**不用红 / 绿语义色——错误也是墨**（clay 2px 左标 + 文字），红底块是廉价警报。
- 材质只有一样：全站已有的 `.texture-overlay` 颗粒（不动色相，所以不脏）。**禁止阴影、禁止渐变、禁止圆角**（`border-radius: 0`）。
- 为什么这样不土：土来自「纯白卡片 + 大阴影 + 圆角」三件套——白比底色亮、阴影伪造光源、圆角伪造柔软，三者都在假装屏幕是一张纸。这里层次只来自**线宽（1px / 2px / 3px）与字重（400 / 500 / 700）**，所有灰都是同一色相的墨量差，读起来是「同一张纸上的不同压力」，不是「一堆浮起来的块」。

## E. 动效清单（只碰 transform / opacity / clip-path；`prefers-reduced-motion` 全部 0.001s 或直接终态）

| 名字 | 触发 | 时长 / 曲线 | 动什么 |
|---|---|---|---|
| `ruleDraw` | 页面进入 | 0.5s `(.2,.9,.2,1)`，错峰 0/60/120ms | 三条主发丝线 `scaleX(0→1)`，`transform-origin: 0 50%` |
| `lineReveal` | 标题 / 栏号入位 | 0.42s `(.22,1,.36,1)`，行 stagger 40ms | `clip-path: inset(0 0 100% 0) → inset(0)`（自下向上揭示） |
| `railUnfold` | 词典栏展开 / 收起 | 0.46s `(.22,1,.36,1)` | 栏 `clip-path: inset(0 0 0 100%) → inset(0)`；**列宽瞬时切换**；栏内文字 `translateX(12px→0)` |
| `axisIgnite` | 字段获得焦点 | 0.18s / 0.24s `(.2,.8,.2,1)` | 栏号转 `clay` + `translateX(-6px→0)`；下划线 `scaleX(0→1)` origin 左端（2px clay） |
| `slugIn` | 加入一条释义 | 0.3s `(.2,.8,.2,1)` | 新行包裹层 `grid-template-rows: 0fr→1fr`，行内 `clip-path: inset(0 0 100% 0)→inset(0)`；栏号数字 `translateY` 翻牌 |
| `seal` | 保存成功 | 0.6s `(.22,1,.36,1)` | 「保存」字块 `translateX(8px)` 换成「已存 12:04」；一条 2px clay 线 `scaleX(0→1)`，40% 处换 origin 再 `scaleX(1→0)` 收回；纸面 `translateY(-4px)` |
| `rowTypeIn` | 列表行出现（义项 / 标签） | 0.3s，stagger 28ms（上限 8 行） | `clip-path: inset(0 100% 0 0) → inset(0)`（沿左轴向右揭示） |
| `strikeOut` | 删除草稿行 | 0.3s + 0.26s | 文字 `clip-path: inset(0 0 0 100%)` 收回；删除线 `scaleX(0→1)`；行 `grid-template-rows: 1fr→0fr` |
| `scanLine` | 词典加载 | 1.1s infinite alternate | 三条 1px 线 `opacity: .28↔.55`（宽 84/62/92%），保持线条母题 |

- 为什么不是「常规淡入」：淡入把「元素是否存在」表达成透明度，任何模板都能这么做，所以读起来是通用组件；这套只动**版面几何**，且方向有语义——左轴阅读对应「从左揭示」，新行入盘对应「从下展开」，保存对应「线从生到灭」。**关掉颜色也能读懂发生了什么**，这是它区别于 fade 的唯一证据。
- 三条硬规则：入场动画全部 < 0.62s（沿用 index.css 的 View Transition 口径，避免 settle 后二次入场）；新类名必须登记进 `index.css` 的 `html.vt-running` 与 `prefers-reduced-motion` 名单；不做 `width/height/top/left/filter/box-shadow` 过渡，唯一例外是 `grid-template-rows` 的单行展开（一次一行，代价可忽略）。
- 词典栏展开为什么不 animate 宽度：宽度动画每帧重排整列文字度量（输入框、换行、光标位置），是掉帧与输入卡顿的直接来源。**布局一帧完成，之后 0.46s 全在合成层**——用遮罩揭示换掉宽度动画，这是性能决定，也正好是这套动效的语言。

## F. 三档降级

- **≥1280**：全部结构。词典栏初始常开（收起后表单吃掉 432，尾栏仍在）。
- **768–1279**：标记栏在 <1024 时塌回字段上方（栏号与标签同行）；词典栏默认开、336 / 272 宽；「全部加入」从底栏移到来源行右侧（省一行高）。
- **390**：上下分屏（见 B）。降级清单：① D0 88→48，标记栏塌成「栏号 + 标签」一行；② 词典结果只保留「义项 + 加入」，例句折成「例句 N 条」一行（点开在原位展开，仍是行内，不弹层）；③ 来源切换是三个 44px 文字标签、`flex-wrap` 换行，**禁止横向滚动收纳**；④ 命中区 = 行高 44 / 48，文字块左右 padding 16，任何控件不缩到 44 以下；⑤ 保存条固定在表单区底部（不是视口底部），永远在把手上方，避让 `env(safe-area-inset-bottom)`。
- **验收**：390×844 下每个可点元素 `getBoundingClientRect()` ≥ 44×44，且 `document.scrollingElement.scrollWidth === 390`；分屏两档下表单首字段与词典搜索框都无需滚动即可点击。

## G. 三个必须禁止的「丑」

1. **白底圆角卡片 + 大阴影 + 遮罩弹窗**（现实现的观感来源）→ 替代：`border-radius: 0`、零阴影；表单与标签页都是整屏纸面（现有 `Modal page` 形态），词典是并置栏；一切分组用发丝线与双线，不用「浮起来的块」。
2. **一排等权圆角胶囊按钮**（保存 / 取消 / 词典 / 全部加入 同尺寸并排）→ 替代：动作只有三级，靠字重与线区分。主 = 实心 charcoal 字块（行高 48、左右 24、方角）；次 = 只有 1px 下划线的文字；三级 = 纯文字，hover 时下划线从左生长。词典的「全部加入」是全局**唯一**实心块，因此自动成为主操作。
3. **居中空态插画 + 圆形图标底 + 三行说明文案** → 替代：空态就是版面本身——左轴一行栏号 + 一行 D1 衬线大字（「未查询」/「没有结果」/「离线」）+ 一条 1px 线，左对齐、不居中、不插图、不写帮助文案。加载 / 空 / 错三态共用同一高度，只换线型（三段闪线 / 实线 / clay 2px 线），切换零跳动。
